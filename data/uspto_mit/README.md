Download `uspto_mit_blockspace.zip` from Zenodo (https://doi.org/10.5281/zenodo.23669984) and unpack
`train.jsonl`, `val.jsonl` and `test.jsonl` into this directory. The archive's README describes the fields and the
blockspace filter (`success` and 1 to 4 elementary steps) that selects the 334,510 training reactions.
